# Calendar by Numio

A clean, private calendar for Android, with an optional Malayalam layer (Kollavarsham dates, nakshatram, Kerala festivals) and an optional Hijri layer.

No ads. No tracking. No internet permission.

**Status:** early work in progress. The month view runs; events and the calendar layers are coming.

## Planned

- Month, week and day views
- Your phone's calendars (including Google) plus private events kept only on your phone, behind a fingerprint lock
- Malayalam layer: Kollavarsham date under each day, nakshatram, Kerala festivals and holidays
- Hijri layer: Islamic date under each day, Islamic occasions, moon-sighting adjustment (−1 / 0 / +1 day)
- Dark, light or follow-system theme

## Built with

Kotlin, Jetpack Compose. Minimum Android 8.0 (API 26).

## Part of Numio

Calendar is part of the [Numio](https://getnumio.org) family of open-source Android apps, alongside Numio Calculator, Clock by Numio, Notes by Numio, Ezhuthola and Decibel.
